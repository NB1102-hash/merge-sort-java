# Merge Sort Implementation (Java)

This project contains a Java implementation of the merge sort algorithm.

## Project Overview

The program implements a recursive merge sort to sort a list of elements into ascending order. It demonstrates understanding of:

- Recursion
- Divide-and-conquer algorithms
- Object-oriented programming
- Basic testing and debugging
- Version control using Git

## Technologies Used

- Java
- Git / GitHub

## How to Run

1. Clone the repository:
   git clone https://github.com/NB1102-hash/merge-sort-java.git

2. Compile the Java files.

3. Run the main class to test the sorting functionality.

This project was completed as part of a Software Design module.
